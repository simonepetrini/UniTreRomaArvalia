# UniTreRomaArvalia
Il progetto prevede la costruzione di un database relazionale di tipo OLTP per l'organizzazione di vari aspetti legati alla registrazioni delle iscriizioni ai vari corsi accademici e la realizzazione di un portale CRM sviluppato con la libreria TKinter di Python per la gestione delle iscrizioni a UniTre Roma Arvalia.
